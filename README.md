# ATM
Merupakan aplikasi untuk membuat simulasi mesin ATM sederhana yang memiliki beberapa fungsi sederhana meliputi :
- Login Akun
- Cek Saldo
- Cek Transaksi
- Tarik Tunai

Aplikasi ini dibuat sesedehana mungkin dengan menggunakan html, css, php dan database MySQL/ MariaDB.

Untuk menggunakan silahkan jalankan query sql / import database yang berada di `database`/`db_atm.sql`, lalu atur konfigurasi `$host` pada file `config.php`, atur menggunakan `localhost` atau menggunakan IP address komputer.
